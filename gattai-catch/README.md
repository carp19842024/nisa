# 合体キャッチ

落ちてくるパーツを正しい順番で受け止めてロボットを完成させる、ブラウザ用のキャッチ系アクションゲーム。

- `index.html` 1ファイルで完結（外部ライブラリ・画像・音声ファイルなし）。ダブルクリックで開けば遊べる
- 操作：ドラッグ、画面の左右を長押し、← → / A D キー。Space / Enter で開始・リトライ、Esc / P で一時停止、M でミュート
- 調整値はファイル先頭の `CONFIG` にまとめてある。機体は `ROBOTS` 配列に足すだけで増やせる
- パーツの絵は `PART_DRAWERS`（種別ごと）と `drawPart()` に集約。ドット絵に差し替えるときはここだけ変える
- URL に `?debug` を付けると、当たり範囲・受け止めライン・判定幅を表示する
- ハイスコアは localStorage の `gattai-catch:best`、ミュート状態は `gattai-catch:mute`、遊び方の既読は `gattai-catch:howto`
