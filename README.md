# つみたて！（暴落チキンレース）

NISAの積立投資をテーマにした、ブラウザで遊べるミニゲーム。
主人公は株価チャートの線の上を走り続け、暴落が来たら飛んでくる「誘惑」を払いのけながら線にしがみつきます。

> このゲームは架空のシミュレーションで、投資助言ではありません。登場するファンドや値動きは架空のもので、将来の運用成果を示すものではありません。

## 遊び方

- 平常時は見ているだけ。高値から10%以上下がると握力がじわじわ減り、悲鳴コメント（**誘惑**）が右から左へ流れてくる。主人公の位置の縦ライン（点線）を越えると握力が減るので、越える前に**タップ・スワイプで払いのける**（PCはクリック、またはスペースキーでいちばん近いものを払う）
- 緑の「役に立つ言葉」はラインを越えると握力が回復する。払いのけてしまうと減る
- 握力が0になると手を離して全額売却（狼狽売り）
- 積立設定で、月5万円を4本の架空ファンド（ぜんぶ入り／ロケットテック／まったりバランス／キンキラ金）と生活防衛資金に振り分ける
- 主人公が走る線は「今持っているファンド全体」の値動き。分散するほど暴落時の下落が浅くなり、握力も減りにくい
- 画面下のファンドのボタン（4本とも常に表示）
  - **1秒長押し**：そのファンドを全部売る。代金は生活防衛資金に入り、そのファンドの積立も止まる（PCは 1〜4 キー長押し、S キー長押しで全部）
  - **短く押す**：そのファンドの設定。毎月の積立額の変更（積立額の合計は余裕資金の範囲まで。残りは貯金）と、生活防衛資金からのまとめ買い。最初に選ばなかったファンドも途中から始められる（PCは 1〜4 キー）
  - B キー：売って止めたファンドの積立を、売る前の積立額で再開
- NISA の購入上限：年間 360万円・生涯 1,800万円（簿価。売った分は翌年に復活）。つみたて投資枠と成長投資枠は区別しない。上限を超える分は買えず生活防衛資金に残る
- 一時停止：右上のボタン、または Esc / P キー
- BGM：最初は OFF。タイトル・注意事項・積立設定ではタイトル曲、プレイ中はプレイ曲、結果画面では流さない。タイトルの「BGM：ON/OFF」・右上の ♪ ボタン・一時停止メニュー・M キーで切り替え。設定はブラウザに保存
- URL に `?seed=123` を付けると、同じ値動き・同じライフイベントで遊べる

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # シミュレーションのテスト（Vitest）
npm run build     # 型チェック＋ dist/ に静的ファイルを出力
npm run preview   # ビルド結果の確認
```

`dist/` は静的ファイルだけなので、GitHub Pages / Netlify などにそのまま置けます（相対パスでビルド）。

## 計算のルール

- 1か月 = 約0.75秒。毎月初に積立（止めているファンドの分は生活防衛資金に残る）→ ライフイベントの支払い。売買はその月の基準価額で行う
- 売った代金は生活防衛資金に入る。まとめ買いは生活防衛資金から（残高と NISA の残り枠の範囲まで）
- ライフイベントの支払いは「生活防衛資金 → ファンドの強制売却（時価に比例）」の順。それでも足りない分は借金（防衛資金がマイナス）
- NISA の損益 = 最終評価額 ＋ NISA から出したお金（売却・強制売却）− NISA に入れたお金（積立・まとめ買い）
- 非課税になった額（課税口座なら払っていた税金の目安）= max(0, 損益) × 20.315%
- 「ずっと持ち続けていたら」= 同じ値動き・同じ積立・同じライフイベントで、自分では一度も売らなかった（手も離さなかった）場合。比較とハイスコアは資産の合計（NISA＋生活防衛資金）で行う
- ゲーム中の操作は操作ログ（月・種類）として記録し、結果画面ではそれを最初から再生して計算する
