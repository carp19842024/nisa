# しがみつけ！（暴落チキンレース）

NISAの積立投資をテーマにした、ブラウザで遊べるミニゲーム。
主人公は株価チャートの線の上を走り続け、暴落が来たら画面を連打して線にしがみつきます。

> このゲームは架空のシミュレーションで、投資助言ではありません。登場するファンドや値動きは架空のもので、将来の運用成果を示すものではありません。

## 遊び方

- 平常時は見ているだけ。高値から10%以上下がると握力が減り始めるので、**画面を連打**（PCはスペースキー）して保つ
- 握力が0になると手を離して全額売却（狼狽売り）
- 「売る」は **1秒長押し**（PCは S キー長押し）。売却中は「買い戻す」（PCは B キー）で戻れる
- 一時停止：右上のボタン、または Esc / P キー
- URL に `?seed=123` を付けると、同じ値動き・同じライフイベントで遊べる

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm test          # シミュレーションのテスト（Vitest）
npm run build     # 型チェック＋ dist/ に静的ファイルを出力
npm run preview   # ビルド結果の確認
```

`dist/` は静的ファイルだけなので、GitHub Pages / Netlify などにそのまま置けます（相対パスでビルド）。

## 構成

```
src/
  main.ts            起動、画面遷移、入力、画面サイズ
  config.ts          調整用の数値すべて（値動き・暴落シナリオ・握力・イベント・演出・称号）
  sim/               描画に依存しない純粋なロジック
    rng.ts           シード付き乱数
    market.ts        値動き生成（幾何ブラウン運動＋暴落シナリオ）
    portfolio.ts     積立・売却・買い戻し・強制売却、操作ログの再生
    events.ts        ライフイベントのスケジュール
    titles.ts        称号判定
    result.ts        結果画面の数値（「ずっと持ち続けていたら」との比較）
  game/
    loop.ts          ゲームループ、時間の進み、主人公の状態
    grip.ts          握力
    renderer.ts      Canvas 描画（チャート・主人公・赤い縁・揺れ・紙吹雪）
    sprites.ts       スプライト定義と読み込み（無ければプレースホルダーを描画）
    comments.ts      流れる悲鳴コメント（3段階）
    audio.ts         サウンドの差し込み口（今は無音）
  ui/                タイトル・注意事項・積立設定・結果・HUD などの HTML 画面
tests/sim/           シミュレーションのテスト
public/sprites/      主人公のスプライト（置けば自動で差し替え）
```

## 計算のルール

- 1か月 = 約0.75秒。毎月初に積立（売却中は現金に貯まる）→ ライフイベントの支払い。売買はその月の基準価額で行う
- ライフイベントの支払いは「生活防衛資金 → 売却中の現金 → ファンドの強制売却」の順。それでも足りない分は借金（防衛資金がマイナス）
- 損益 = 最終評価額 ＋ 生活費として引き出した額 − 積立元本
- 非課税になった額（課税口座なら払っていた税金の目安）= max(0, 損益) × 20.315%
- 「ずっと持ち続けていたら」= 同じ値動き・同じ積立・同じライフイベントで、自分では一度も売らなかった（手も離さなかった）場合
- ゲーム中の操作は操作ログ（月・種類）として記録し、結果画面ではそれを最初から再生して計算する
