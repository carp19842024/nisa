# スプライト置き場

ここに PNG を置くと、ゲームが自動で読み込んで差し替えます（置かれていないものはプレースホルダーで描画）。

| ファイル名 | 用途 | コマ数 |
|---|---|---|
| `run.png` | 平常時の走り | 4（横並び） |
| `run_happy.png` | 上昇中の走り | 1 |
| `shock.png` | 暴落の始まり | 1 |
| `cling.png` | しがみつき（握力50以上） | 1 |
| `cling_cry.png` | しがみつき（握力50未満） | 1 |
| `fall.png` | 手を離して落ちる | 1 |
| `walk.png` | 売却後に地面を歩く | 2 |
| `sad.png` | 膝を抱えて座る（結果画面・強制売却時） | 1 |
| `victory.png` | 回復時・好成績の結果画面 | 1 |

- 1コマ 64×64px、背景透過、右向き。コマは横に並べる（`run.png` なら 256×64）。
- コマ数やサイズを変えたいときは `src/game/sprites.ts` の `SPRITE_DEFS` を編集してください。
  画像の幅が「コマ数×コマ幅」と合わない場合は、横幅をコマ数で割ったサイズで自動的に切り出します。
- しがみつき（`cling` / `cling_cry`）は、画像の**上端中央**が線にぶら下がる位置になります。それ以外は**下端中央**が足元です。
