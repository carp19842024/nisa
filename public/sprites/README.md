# スプライト置き場

ここに PNG を置くと、ゲームが自動で読み込みます。どの画像をどのコマに使うかは `src/game/sprites.ts` の `SPRITE_DEFS` で決めています。

| 用途 | ファイル | 備考 |
|---|---|---|
| 平常時の走り | `run01.png`〜`run06.png` | 1コマ1ファイル。並び順に再生してループ（`run07.png` は `run01.png` と同じ画像なので使っていない） |
| 上昇中の走り | `run_happy.png` | |
| 暴落の始まり | `shock.png` | |
| しがみつき（握力50以上） | `cling.png` | 画像の**上端中央**が線にぶら下がる位置 |
| しがみつき（握力50未満） | `cling_cry.png` | 同上 |
| 手を離して落ちる | `fall.png` | **未作成**。無い間は `shock.png` を回転させて代用 |
| 売却後に地面を歩く | `walk.png` | **未作成**（2コマ横並びの想定）。無い間は走りの画像をゆっくり再生して代用 |
| 膝を抱えて座る | `sad.png` | 結果画面・強制売却時 |
| 回復時・好成績 | `victory.png` | |

- 背景透過、右向き。キャラクターは各コマの**下端中央**に足元をそろえる。
- 画像の大きさは自由（今は 400×560）。読み込み時にゲーム内の高さ `SPRITE_HEIGHT`（80px）へ段階的に縮小し、ゲーム画面ではドット絵風に拡大表示する。
  設定・イベント・結果などの HTML 画面では、縮小前の元画像からなめらかに表示する。
- ファイル名は大文字・小文字を区別するサーバーがあるので、すべて小文字にそろえる。
- 画像が無いスプライトは、代わりのスプライト（`fallback`）→ それも無ければドット絵のプレースホルダーで表示する。
